# طلبات السحب تُنشأ تلقائياً

## الحكم الأساسي
- عند دفع فرع المهمة إلى المستودع البعيد عبر `git push -u origin <branch>`، يُنشأ طلب السحب تلقائياً هناك.
- لا يوجد أي عمل محلي مطلوب بخصوص طلبات السحب، ولا يُعدّ إنشاؤها خطوة من خطوات المهمة.

## المحظورات
- يُمنع تقديم خيار «فتح PR» أو «إنشاء طلب سحب» في الاقتراحات التفاعلية أو في أي رد نصي.
- يُمنع إنشاء طلب سحب أو التحقق منه أو تعديله بأي أداة محلية (CLI أو API).
- يُمنع ذكر طلب السحب كخطوة تالية في التقارير أو الملخصات أو خطط العمل.

## السلوك المطلوب
- الالتزام بسير العمل المعتاد فقط: إنشاء الفرع، الالتزام، الدفع، ثم العودة إلى الفرع الأساسي.
- عند اقتراح خطوة تالية، تقتصر الخيارات على أعمال الكود والاختبار والمراجعة البشرية، دون أي خيار مرتبط بطلبات السحب.

# Form Input & Iconography Rules

Related: [[rules]]

## Form Inputs
- For phone number input fields, ALWAYS use `CustomPhoneFormField` located at `@lib/core/widgets/forms/custom_phone_form_field.dart`.

## Iconography
- **ALWAYS** use icons from `Fontawesome` or `lucide_icons_flutter`.
- **TRY TO AVOID** standard Material `Icons` (`Icons.xxx`) as much as possible.

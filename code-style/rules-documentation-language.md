# لغة التوثيق (Documentation Language)

## القاعدة
تُكتب التعليقات والتوثيق داخل ملفات المشروع وملفات القواعد **بالعربية**، تماشياً مع لغة المستخدم وكتابة القواعد.

## الاستثناءات
- أسماء المتغيرات والدوال والملفات تبقى بالإنجليزية وفق اصطلاح Dart/Flutter.
- المصطلحات التقنية (مثل `BLoC`، `repository`) تُكتب كما هي، ويكون الشرح حولها بالعربية.

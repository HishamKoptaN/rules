# الاختبارات على بيئة `dev` فقط

قاعدة ملزمة لكل وكيل يعمل في هذا المستودع أو في أي مشروع يعتمد على هذه القواعد.

## الحكم الأساسي
- كل اختبار يدوي أو آلي يُطبَّق **حصراً على بيئة `dev`** (مثلاً الرابط `https://greensoouq-dev.web.app` والمشروع `greensoouq-dev`).
- يُمنع تنفيذ أي اختبار، أو إدخال أي بيانات، على **بيئة الإنتاج** — حتى لو كان الاختبار "مجرد تجربة" أو بدون تعديل دائم.

## ما يُعد اختباراً
- إنشاء حسابات مستخدمين أو تسجيل الدخول بأي طريقة (بريد/كلمة مرور، Google، زائر، أو غيرها).
- إرسال روابط إعادة تعيين كلمة المرور، تغيير البيانات، رفع ملفات، أو حذف محتوى تجريبي.
- استدعاء واجهات API بالبيانات الحقيقية أو بيانات اختبار، واختبار الدفع أو الإشعارات.

## قبل التنفيذ
1. تحقق أن الرابط أو معرّف المشروع أو `baseUrl` المستخدم يشير إلى `dev` فعلاً.
2. إن تعذّر الوصول إلى `dev`، أوقف الاختبار وأبلغ المستخدم، ولا تستخدم بيئة الإنتاج كبديل.
3. سجّل في تقرير الاختبار اسم البيئة والتاريخ ونتائج كل طريقة تم اختبارها.

## الاستثناءات
- لا استثناء بدون **موافقة صريحة ومسبقة من المستخدم**، وبعد توضيح الأثر المتوقع بالضبط.
